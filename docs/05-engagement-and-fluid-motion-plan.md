# 재미 요소 및 Fluid Motion 기획

## 1. 목표 경험

이 앱의 핵심 감정은 **공부를 시작한다**보다 **5분짜리 가벼운 게임을 연다**에 가깝게 만든다.

- 한 번의 학습은 계속 5단어, 약 5분으로 유지한다.
- 같은 단어라도 매일 문제 방식과 배치가 조금씩 달라진다.
- 정답은 손끝에 붙었다가 제자리로 들어가는 듯한 만족감을 준다.
- 오답은 벌점처럼 보이지 않고, 부드럽게 원래 자리로 돌아오며 힌트를 남긴다.
- 물 같은 효과는 배경 장식이 아니라 사용자의 클릭·드래그·진행도에 반응할 때만 사용한다.

## 2. 지루하지 않게 만드는 학습 구조

### 기본 5분 루프

1. **오늘의 5단어 공개** — 뜻과 발음을 짧게 확인한다.
2. **기억 깨우기** — 방금 본 단어 중 하나를 가리고 뜻을 떠올린다.
3. **연결 게임** — 단어와 뜻을 매칭한다.
4. **문장 조립** — 난이도에 맞는 짧은 문장을 만든다.
5. **오늘의 변주 게임** — 단어찾기 또는 아래 게임 중 하나가 번갈아 나온다.
6. **마무리 리캡** — 오늘 잘 기억한 단어와 다시 볼 단어를 한 화면에 보여준다.

모든 단계를 길게 늘리지 않는다. 각 단계는 30~70초, 전체는 4~6분을 목표로 한다.

### 추가할 게임 변주

#### A. 듣고 잡기

단어 발음을 들려주고 3개의 뜻 카드 중 맞는 것을 누른다. 철자를 먼저 보여주지 않아 듣기 기억을 별도로 강화한다.

#### B. 의미 버블

한국어 뜻이 중앙에 나오고 영어 단어 버블이 천천히 떠오른다. 맞는 버블을 누르면 중앙으로 빨려 들어가며 합쳐진다. 물 같은 모션을 가장 자연스럽게 활용할 수 있는 게임이다.

#### C. 빈칸 한 조각

짧은 문장에서 오늘의 단어만 비우고 3개 후보 중 하나를 끌어 넣는다. 기존 문장 전체 조립보다 쉬워 초급 단계에서 먼저 사용한다.

#### D. 철자 흐름

흩어진 글자 5~8개를 순서대로 훑거나 눌러 단어를 완성한다. 너무 긴 단어에는 사용하지 않는다.

#### E. 빠른 분류

카드를 좌우로 밀어 두 의미 범주로 나눈다. 예: 행동/사물, 긍정/중립. 단어 데이터에 범주가 충분히 쌓인 뒤 추가한다.

### 매일 달라지는 조합 규칙

- **고정:** 단어 공개 → 매칭 → 마무리 리캡
- **난이도별 문장:** 초급은 빈칸 한 조각, 익숙해지면 문장 조립
- **회전 슬롯:** 단어찾기 / 듣고 잡기 / 의미 버블 / 철자 흐름 중 하나
- 전날과 같은 회전 게임은 되도록 피한다.
- 최근 틀린 단어는 다음 날 다른 게임 방식으로 다시 등장시킨다.

이 구조라면 학습 원칙은 유지하면서도 매일 화면과 손동작이 달라진다.

## 3. 동기와 보상

### 즉시 보상

- 연속 정답 2회부터 작은 `COMBO` 표시를 사용한다.
- 정답 카드가 정답 위치로 흡수되며 진행 바에 작은 물방울이 더해진다.
- 오답 후 바로 정답을 맞히면 `다시 찾아냈어요`로 회복을 강조한다.
- XP 숫자는 단순 증가가 아니라 이전 숫자가 밀려 올라가며 바뀐다.

### 세션 보상

- 별점 대신 `오늘의 기억 온도` 또는 `기억 게이지`를 보여준다.
- 결과는 `잘 기억해요 / 한 번 더 보면 좋아요` 두 그룹으로만 나눈다.
- 완료 화면에서 가장 어려웠던 단어 하나만 3초 복습할 수 있게 한다.

### 장기 보상

- 연속 출석 숫자보다 **학습 물결**을 사용한다. 학습한 날마다 주간 그래프에 물방울이 채워진다.
- 단어별 숙련도를 `처음 봄 → 익숙함 → 기억함` 3단계로 관리한다.
- 5일마다 작은 테마 색상, 배경 오브, 게임 보드 스킨을 해금한다.
- 경쟁형 리더보드는 넣지 않는다. 짧고 편안한 학습 분위기와 맞지 않는다.

## 4. 물 같은 물리 모션 방향

### 모션 성격

완전히 출렁이는 UI가 아니라, **누르면 눌리고 놓으면 붙으며 이동하면 살짝 늘어나는 인터페이스**로 정의한다.

1. **Press** — 버튼이 0.97배로 눌리고 그림자가 짧아진다.
2. **Release** — 1.015배까지 가볍게 복원된 뒤 1로 안정된다.
3. **Drag** — 드래그 방향으로 요소가 2~4% 늘어나고 반대 축은 살짝 줄어든다.
4. **Snap** — 목표 지점 근처에서 자석처럼 빨려 들어간다.
5. **Merge** — 정답 요소가 목표 요소와 겹치며 색이 섞인 뒤 하나로 정리된다.
6. **Reject** — 오답은 붉게 흔들리지 않고 호박색 테두리와 함께 탄성 있게 원위치한다.

### 적용 위치

- 홈의 오늘 학습 오브: 포인터와 진행도에 따라 내부 그라디언트가 천천히 이동한다.
- 진행 바: 직선 막대 안에서 액체 표면이 2~3px 정도만 움직인다.
- 매칭: 선택한 두 카드 사이에 선 대신 점성 있는 연결 띠가 늘어난다.
- 문장 만들기: 토큰을 옮길 때 빈 슬롯이 먼저 벌어지고, 토큰이 붙으며 주변 토큰이 밀린다.
- 단어찾기: 선택 경로를 개별 칸 색칠이 아닌 이어진 젤 리본처럼 표현한다.
- 정답: 작은 원형 파동이 한 번 퍼지고 250~400ms 안에 사라진다.
- 화면 전환: 이전 카드가 아래로 사라지고 다음 카드가 위로 등장하는 대신, 중심 카드가 형태를 바꾸는 듯한 연속성을 준다.

### 사용하지 않을 곳

- 긴 본문 텍스트
- 하단 메뉴의 상시 움직임
- 설정 화면
- 타이머 숫자 전체의 반복 흔들림
- 동시에 세 곳 이상에서 반복되는 장식 애니메이션

사용자가 집중해야 하는 게임 영역만 살아 움직이고 나머지는 안정적으로 유지한다.

## 5. 프레임워크 없는 구현 방식

### CSS 모션 토큰

```css
:root {
  --motion-tap: 120ms;
  --motion-snap: 240ms;
  --motion-flow: 420ms;
  --ease-out: cubic-bezier(.22, 1, .36, 1);
  --ease-spring: cubic-bezier(.34, 1.56, .64, 1);
  --ease-fluid: cubic-bezier(.2, .8, .2, 1);
}
```

- 눌림은 120ms 내외로 즉시 반응한다.
- 카드 이동과 정답 흡수는 220~280ms로 맞춘다.
- 화면/진행도 변화는 360~480ms를 사용한다.
- 무한 반복 장식은 최소화하고 4초 이상의 매우 느린 움직임만 허용한다.

### JavaScript 모션 엔진

외부 라이브러리 없이 다음 세 가지만 사용한다.

- `requestAnimationFrame`: 드래그 위치, 속도, 늘어남 계산
- Web Animations API: 정답, 오답, 화면 전환의 취소 가능한 애니메이션
- CSS Custom Properties: `--x`, `--y`, `--velocity`, `--progress`를 DOM에 전달

간단한 스프링은 매 프레임 아래 값을 계산한다.

```text
가속도 = (목표 위치 - 현재 위치) × stiffness - 속도 × damping
속도 += 가속도
현재 위치 += 속도
```

초기 권장값은 `stiffness 0.14`, `damping 0.72`이며 실제 기기에서 조절한다. 저사양 기기에서는 blur와 SVG 필터를 끄고 transform/opacity만 유지한다.

### 물 표현 방식

- 기본: 다중 radial-gradient, border-radius 변형, transform
- 연결/합쳐짐: 작은 인라인 SVG와 제한적인 `feGaussianBlur + feColorMatrix`
- 모바일 저사양 또는 `prefers-reduced-motion`: SVG 점성 필터 제거
- Canvas는 단어찾기 연결 리본처럼 DOM으로 표현하기 어려운 한두 영역에만 검토한다.

### 접근성과 성능 기준

- `prefers-reduced-motion: reduce`에서는 튕김·출렁임을 제거하고 100ms 페이드로 대체한다.
- 애니메이션 중에도 버튼의 실제 클릭 영역은 이동시키지 않는다.
- transform과 opacity 중심으로 구현해 레이아웃 재계산을 줄인다.
- 한 화면의 계속 움직이는 요소는 최대 2개로 제한한다.
- 모바일 기준 60fps, 저사양 기준 최소 30fps를 QA 기준으로 둔다.

## 6. 우선순위

### P0 — 먼저 해야 할 것

1. 공통 모션 토큰과 `prefers-reduced-motion` 구축
2. 모든 버튼의 press/release, 카드 등장/퇴장 통일
3. 정답/오답/진행도 피드백을 물리 모션으로 통일
4. 단어찾기 선택 경로를 이어진 젤 리본으로 개선
5. 세션 종료 리캡과 단어별 `잘 기억함 / 다시 보기` 저장

P0만 적용해도 앱 전체가 훨씬 부드럽고 완성도 있게 느껴진다.

### P1 — 재미의 반복성 개선

1. 듣고 잡기
2. 빈칸 한 조각
3. 의미 버블
4. 매일 회전 게임 선택 알고리즘
5. 콤보와 기억 게이지

### P2 — 오래 쓰게 만드는 기능

1. 단어별 3단계 숙련도
2. 틀린 시점에 따른 간격 복습 일정
3. 주간 학습 물결과 5일 단위 테마 해금
4. 간단한 효과음 및 진동 설정
5. 전공별 단어 묶음과 스몰 토크 연계

## 7. 권장 개발 순서

### 1차: 촉감 개선

버튼, 카드, 토큰, 진행 바, 정답/오답을 하나의 모션 규칙으로 묶는다. 기존 기능은 바꾸지 않고 체감 품질부터 올린다.

### 2차: 학습 변주

빈칸 한 조각과 듣고 잡기를 추가하고, 기존 문장 조립/단어찾기와 난이도별로 교대시킨다.

### 3차: 물 같은 대표 장면

의미 버블과 젤 리본 단어찾기를 구현한다. 이 두 장면을 앱의 시각적 정체성으로 삼는다.

### 4차: 기억 시스템

단어별 숙련도와 복습 간격을 저장하고 홈/복습/통계 화면을 연결한다.

## 8. 완료 기준

- 어떤 화면에서도 클릭 후 100ms 안에 시각 반응이 보인다.
- 정답, 오답, 드래그, 단계 이동의 움직임이 서로 다른 규칙처럼 느껴지지 않는다.
- 5일 연속 사용해도 회전 게임의 조합이 완전히 같지 않다.
- 물 효과가 학습 내용을 가리거나 텍스트 가독성을 낮추지 않는다.
- 모바일과 데스크톱 모두 전체 페이지가 아니라 게임 영역 안에서 자연스럽게 동작한다.
- 모션 감소 설정과 키보드 조작에서도 학습을 끝까지 완료할 수 있다.
