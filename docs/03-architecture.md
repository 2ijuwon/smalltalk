# 초기 프로젝트 구조

프레임워크와 빌드 과정이 없는 정적 웹 앱이다. HTML, CSS, 브라우저 표준 JavaScript ES 모듈만 사용한다. 계정이나 외부 API 없이 브라우저 저장으로 시작하며, 학습 정책은 DOM 코드와 분리한 순수 함수로 둔다.

```text
index.html              문서 진입점
src/
  app.js                화면 렌더링·이벤트 위임·상태 조합
  data.js               전공별 검토용 샘플 콘텐츠
  domain.js             학습·채점·복습·저장 정책
  styles/app.css        명세 토큰·공통 컴포넌트·반응형
tests/learning.test.mjs 기록 분리·복습·중복 처리 검증
docs/                   디자인·기능 우선순위·구조
public/assets/          확보한 Figma 원본 에셋을 둘 위치
```

## 상태 경계

장기 저장: 전공·난이도·일일 목표·알림 희망 시간, 콘텐츠별 학습 상태, 결과 이력, 즐겨찾기, 다시 볼 사유, XP.

일시 상태: 현재 화면·카드 인덱스·뜻 공개·선택 답·음성 재생. 화면 이동 시 필요한 UI 상태를 초기화한다.

저장 스키마 버전은 1이다. 다른 버전이나 손상 데이터는 자동 덮어쓰지 않고 안내한다. 서비스 도입 시 `domain.js`의 저장 함수를 서버 어댑터로 교체할 수 있다.

## 원본 에셋

`public/assets/`에는 제공받은 로고·가로 배너·몬스터·Noto Sans KR 폰트만 넣는다. Figma MCP 사용량 제한으로 아직 추출하지 못했다. 스크린샷을 앱 배경으로 쓰거나 원본을 임의로 다시 그리지 않는다.

## 다음 개발 단위

1. 샘플 흐름과 문구를 검토한다.
2. 복습·숙달·자동 난이도·XP 정책의 미확정 값을 확정한다.
3. 단어 매칭·문장 배열·듣기를 동일 채점 이벤트에 연결한다.
4. 전투 상태 머신과 타이머 중복 판정 방지를 구현한다.
5. 원본 에셋을 배치하고 Frame 1의 개별 화면과 시각 검수를 마친다.
