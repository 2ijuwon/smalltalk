# small talk — 디자인 규칙

확인일: 2026-11-05. 출처: [Figma 원본](https://www.figma.com/design/4q3YIxjYORiO6OfmGTTI8t/?node-id=0-1)의 **Frame 1**, **디자인 규칙**, **필수 기능 레퍼런스**. ‘필수 기능 레퍼런스 이전 버전’은 보조 자료로만 사용한다.

## 확인 방법과 적용 범위

브라우저로 Frame 1 전체 흐름과 최신 명세를 확대 열람했다. Figma 연결은 완료됐으나 MCP Starter 사용량 제한으로 레이어 속성·에셋 추출은 실패했다. 아래 색상과 치수는 디자인 규칙 원문에 쓰인 값이며, Frame 1의 개별 레이어를 측정한 결과는 아니다. 초기 프로젝트는 명세를 적용한 기능 골격이다. 원본 로고·배너·몬스터·폰트 파일을 임의로 재제작하지 않는다. 현재는 텍스트 브랜드를 사용하며, 원본 에셋 통합과 화면별 픽셀 비교는 후속 작업이다.

## 방향

밝은 전공 영어 학습 화면에 캐주얼 RPG 분위기를 결합한다. 읽는 영역은 흰색 카드, 주요 목표와 행동은 청록색으로 구분한다. 학습 화면은 차분하게, 전투 화면은 체력·시간·문제 상태를 명확하게 표현한다.

## 글꼴과 크기

기본 글꼴은 **Noto Sans KR**. 원본 폰트 파일은 확보 전이므로 CSS 폰트 스택과 시스템 한글 글꼴로 대체하며 실제 로드 여부를 문서화한다.

| 용도 | 크기 |
| --- | --- |
| 화면 제목 | 26px Bold |
| 영어 단어 | 32px Bold |
| 문제 문장 | 20px Bold |
| 본문·버튼 | 16px |
| 해석·보조 설명 | 14px |
| 분류·진행 정보 | 12px |

## 컴포넌트

- 주요 버튼: 높이 56px, 모서리 16px, 아래 받침 4px. 누르면 아래로 이동하며 받침이 줄어든다.
- 보조 버튼: 흰색 바탕, 진한 청록 글자, 경계색 테두리.
- 콘텐츠 카드: 흰색, 모서리 20px, 내부 여백 20px, 경계 1px.
- 퀘스트 카드: 청록색, 목표·진행률·보상을 함께 표시한다.
- 답변 선택지: 최소 높이 56px, 모서리 16px, 패딩 16px, 간격 12px. 긴 문장은 높이가 늘어난다.
- 선택·정답 상태: 청록색 및 진한 청록 테두리 + 텍스트나 확인 아이콘. 색상만으로 구분하지 않는다.
- 체력 바: 몬스터와 사용자가 같은 모양을 사용, 높이 14px. 길이와 현재/최대 숫자 모두 표시한다.
- 키보드 포커스, 마우스 반응, 음성 재생 상태를 명확히 표시한다. 애니메이션 감소 설정을 존중한다.

## 화면 구조

모바일: 한 열, 좌우 24px, 핵심 행동을 아래에 일관되게 배치한다. 넓은 화면: 홈 카드는 여러 열로 배치하되 단어·문제는 읽기 좋은 폭을 유지한다. 전투는 넓은 화면에서 상태와 문제를 두 열로 나눌 수 있다.

- 홈: 브랜드 → 전공·난이도 → 오늘의 퀘스트 → 단어·문장·퀴즈·전투·복습 → 주요 메뉴.
- 학습: 전공·난이도 → 큰 단어 → 한글 발음·음성 → 뜻 확인 → 예문·해석. 즐겨찾기는 카드 우상단.
- 퀴즈: 유형·진행 수치 → 문제 → 답변 → 정답·해설 → ‘확인했어요’.
- 전투: 스테이지 → 몬스터·몬스터 HP → 사용자 HP → 남은 시간 → 문제·답변.
- 전투 주의: HP 20% 이하, 타이머 5초 이하. 시간 종료 시 입력 종료. 화면 전체의 붉은 점멸은 사용하지 않는다.

## 문구 우선순위와 원본 차이

Frame 1에는 ‘오답 노트’, ‘틀렸어요’, ‘패배’, ‘VICTORY!’ 같은 구버전 표현이 남아 있다. 최신 디자인 규칙과 필수 기능 명세가 명시적으로 이를 수정하므로 **배치는 Frame 1**, **사용자 문구·판정 규칙은 최신 명세**를 따른다.

| 상황 | 적용 문구 |
| --- | --- |
| 다시 확인할 목록 | 다시 볼 표현 |
| 정답과 다른 답 | 여기서는 …가 알맞아요. + 실제 정답·설명 |
| 학습 자기 확인 | 기억했어요 / 한 번 더 볼게요 |
| 제한 시간 종료 | 이번 문제의 시간이 끝났어요. |
| 전투 종료·체력 소진 | 이번 도전이 끝났어요. |
| 스테이지 승리 | 스테이지 완료! |

결과를 부드럽게 설명하되 실제 점수·체력·시간은 정확히 보여준다. 완료와 숙달을 같은 뜻으로 처리하지 않는다. 원본 이미지 배너는 홈·온보딩에만 두며 학습·문제·전투에 반복하지 않는다.
