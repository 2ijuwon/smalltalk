# 기능 명세와 우선순위

출처와 검증 한계는 [디자인 규칙](./01-design-rules.md)을 따른다. 아래 P0/P1/P2는 **개발 순서에 대한 제안**이며, Figma가 지정한 우선순위가 아니다. P1도 최신 명세의 초기 버전 완료 기준에 포함되는 항목이므로 출시 전에 완료해야 한다.

## 사용자 흐름

첫 실행: 스플래시 → 온보딩 → 전공 → 초기 난이도 → 홈.
재실행: 저장 설정 복구 → 홈의 오늘 목표·복습 대상.
학습: 단어·문장 → 문제 풀이 → 결과 → 다시 볼 표현·복습 → 통계·설정.
전투: 준비 → 문제·타이머 → 입력 잠금·판정 → 설명 확인 → 다음 문제 / 종료.

## P0 — 기반과 끝까지 동작하는 학습 흐름

| 기능 | 필수 동작 / 완료 기준 |
| --- | --- |
| 초기 설정 | 전공 5종, 난이도 3단계. 설정 변경 후 기존 기록 보존 |
| 홈·오늘의 퀘스트 | 실제 데이터의 학습량·복습 대상·목표를 표시. 샘플 개수를 20개로 부풀리지 않음 |
| 단어 학습 | 영어↔한국어 양방향, 뜻 확인, 한글 발음, 예문·해석, 즐겨찾기, 자기 확인 |
| 문장·상황 학습 | 전공별 문장과 상황, 핵심 어휘, 음성, 학습 기록 |
| 객관식 | 단어↔뜻, 제출 뒤 답·해설, 결과 및 실제 채점 기록 |
| 다시 볼 표현 | 오답·시간 초과·직접 추가를 구분. 같은 항목은 합치되 이력은 보존 |
| 복습 기반 | 마지막 학습·다음 일정·단계·연속 정답. 자기 확인과 채점 결과 분리 |
| 통계 | 고유 학습 단어, 채점 대상 정답률, 실제 학습 일수. 빈 상태 제공 |
| 저장·복구 | 버전이 있는 로컬 저장, 읽기·쓰기 실패 안내, 재실행 시 기록 유지 |
| 디자인 시스템 | 색상·치수 토큰, 카드·버튼·선택지·게이지, 접근 가능한 키보드 조작 |

## P1 — 초기 버전 전체 완료에 필요한 확장

| 기능 | 필수 동작 / 완료 기준 |
| --- | --- |
| 단어 매칭 | 두 열에서 쌍 선택, 재선택·완료 쌍 잠금, 완료 시 결과 저장 |
| 문장 배열 | 단어 조각 선택·취소·전체 초기화, 제출 후 정답 문장·해석 |
| 듣기·TTS | 단어·문장 재생/정지·속도·반복·상태. 실패는 오답으로 집계하지 않음 |
| 전투 | HP 100/100, 정답 피해 20, 다른 답·시간 초과 사용자 피해 20, 문제당 20초 |
| 전투 상태 | 정답·다른 답·시간 종료·저체력·승리·체력 소진. 제출/타임아웃 경합을 한 번만 처리 |
| 보상 | XP·배지, 재도전 중복 보상 방지. 지급 조건은 정책으로 관리 |
| 자동 난이도 | 최근 정답률·오답·응답 시간·복습 단계 기반 규칙, 최소 표본·상하향 조건 확정 필요 |
| 학습 시간·집계 | 백그라운드 시간 제외, 날짜 기준 통일, 반복 학습과 고유 단어 구분 |
| 알림 | 설정 UI와 저장 이후 실제 OS/웹 알림 전달 경로 구현·검증 |
| 브랜드 에셋 | Figma 원본 로고·배너·몬스터·폰트 확보, 실제 화면과 시각 비교 |

Frame 1의 ‘빈칸 채우기’는 최신 명세의 초기 4종(매칭·객관식·문장 배열·듣기)과 표현이 다르다. 초기 구조에는 유형을 확장할 수 있도록 모델을 열어 두고, 기본 완료 기준은 최신 명세를 따른다.

## P2 — 명시적 후속 확장

- 철자 완성, 전공 문장 해석 문제, 듣고 단어 배열.
- STT 말하기 실험: 마이크 권한·녹음·인식 문장·재시도. 발음 평가와 구분.
- 계정·서버 동기화·콘텐츠 편집 도구·검증된 대규모 교육 콘텐츠.
- 실제 사용자 결과에 따른 복습·난이도·게임 수치 조정.

## 데이터와 불변 조건

- 콘텐츠: 단어·뜻·발음·문장·해석·전공·난이도. 사용자 기록과 별도 관리.
- 자기 확인: `remembered`, `again`. 실제 객관식 등의 `correct`, `incorrect`, `timeout`과 별도 기록.
- 다시 볼 이유: `manual`, `incorrect`, `timeout`. 직접 추가는 오답 횟수를 늘리지 않음.
- 즐겨찾기: 관심 표시. 다시 볼 표현·숙달과 별개.
- 완료: 이번 세션의 배정 항목을 마침. 숙달: 반복 채점·복습 기준을 충족함.
- 업데이트 순서: 결과 저장 → 다시 볼 목록 → 복습 일정 → 숙달 → 통계·난이도.
- 정답률 분모는 실제 제출·타임아웃만 포함하며 단어 카드의 자기 확인은 제외.
- 재학습 정답 1회로 과거 이력이나 다시 볼 사유를 삭제하지 않음.
- 전투 종료 후 타이머/오래된 이벤트가 새 세션을 수정하지 못해야 함.

## 미확정 정책 — 개발용 기본값과 확정 필요 사항

| 항목 | 초기 구성 방침 | 출시 전 결정 |
| --- | --- | --- |
| 복습 | 학습 직후→1→3→7→14→30일을 설정 배열로 분리 | 기준 시점·진급·재출제·우선순위 |
| 숙달 | 카드 확인만으로 숙달 판정하지 않음 | 반복 정답 횟수·유지·변경 기준 |
| 적응 난이도 | 기본 난이도 저장, 자동 적용은 후속 | 평가 구간·표본 수·상하향 기준 |
| 전투 | 명세의 HP·피해·20초를 설정 상수화 | 중단·재개, 듣기 타이머 시작점 |
| XP | 샘플 세션 완료에만 지급, 동일 세션 재처리 방지 | 날짜·콘텐츠·재도전별 지급 조건 |
| 알림 | 희망 시간만 저장, 실제 알림을 보냈다고 표현하지 않음 | 플랫폼·권한·서버/OS 전달 방식 |
| 기록 | 로컬 버전 저장 | 다중 기기 동기화·백업·손상 복구 |

## 초기 구성 검수

1. 첫 실행에서 전공·난이도를 고르고 홈으로 이동한다.
2. 단어의 뜻·예문·음성을 확인하고 방향을 바꿀 수 있다.
3. 자기 확인과 실제 퀴즈 채점이 서로 다른 기록으로 남는다.
4. 직접 추가와 다른 답의 다시 볼 이유가 별도로 남는다.
5. 저장 후 새로 열어도 설정과 기록이 유지된다.
6. 게임의 제출과 타임아웃이 겹쳐도 피해는 한 번만 적용된다.
7. 긴 답변·좁은 화면·키보드 이동·음성 미지원 상태를 처리한다.
8. 원본 에셋·미확정 정책·아직 미구현인 기능을 완료로 표시하지 않는다.
